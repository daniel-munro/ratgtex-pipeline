# Genotype-free identity search

Run from the repository root after first-pass identity QC:

```bash
snakemake -s reports/identity_qc/Snakefile --profile slurm -j10 -n
snakemake -s reports/identity_qc/Snakefile --profile slurm -j10
```

The sole search list is [`samples_to_check.tsv`](samples_to_check.tsv), a
headered tab-separated table with columns `tissue` and `sample_id`. Here
`tissue` means the configured source dataset (for example, `NAcc1`, not
`NAcc`). Add or remove rows to choose exactly which samples to check,
including both previously unknown samples and new mismatches. No filtering
by ID or consultation of `samples/relabeled.tsv` occurs during the run.

The current list contains one positive control (`Adipose / 57215-3`) first,
followed by 19 unknown samples and the two Adipose/Liver `64064-4` mismatches
(22 alignments total). Controls are optional ordinary rows. Each sample ID
must appear in its release-local FASTQ map. The workflow groups rows by
dataset and writes internal one-column `samples.txt` files for the comparison
script; edit the central TSV, not these generated files.

FASTQs come from the release-local maps and dataset settings in
`config/config.yaml`. STAR uses the existing read-length-specific reference
index and two-pass alignment, omitting both `--varVCFfile` and
`--waspOutputMode`. Controls and mismatches are also aligned this way so the
controls assess the same procedure. No individual genotype VCFs are required.

Allele counting uses the existing tissue test-SNP VCFs and the same GATK
thresholds as first-pass QC. All-rat comparison uses the existing comparison
script and its fixed-seed 10,000-SNP selection. The shared all-rat exon VCF is
built by the existing genotype rules if needed. Existing tissue test-SNP VCFs
must already have been generated by first-pass QC.

All new alignment files, allele counts, and summaries are under
`reports/identity_qc/genotype_free/{version}/{dataset}/`:

- `alignment/`: coordinate BAMs, indexes, and STAR logs/auxiliary files.
- `samples.txt`: generated dataset-specific sample list.
- `counts/`: allele-count tables, retained independently of BAMs.
- `all_rats_summary.tsv`: top two matches, similarities, and variant counts.
- `tmp/`: project-local temporary storage.

Review the positive control, usable variant counts, top matches, and score
gaps before updating identities. An `unknown-*` ID will have `is_correct=False`
even when its top genotype match is convincing; that field only compares the
RNA label with the genotype label.

BAMs are retained for manual review, rather than automatically deleted.
After review, delete unneeded BAMs and their `.bai` files from these isolated
`alignment/` directories. Keep the count tables and summaries as evidence.
For a resolved sample, update the authoritative sample tracking/FASTQ maps and run the normal
genotype-aware alignment under its confirmed ID; these exploratory BAMs are
not promoted into tissue output directories.
